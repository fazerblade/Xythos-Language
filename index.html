01 / INTRODUCTION

What is Xythos?

Xythos is a constructed language designed for written communication and texting. Instead of writing with ordinary letter names and spellings, each letter is represented by its own form.

When letters appear together, they may follow specific combination rules. This means that understanding Xythos involves learning both the individual letters and how they change when combined.

Letter forms

Each letter has a corresponding written form, such as A = 'a and B = bh.

Combinations

Some adjacent letters combine into a different form, such as I + N = ihn'te.

Spelling

Letter position and repeated letters can affect how a word is written.

Order matters

Reversing a pair can produce a different form. For example, M + N = m'nte, while N + M = n'mt.

Repeated letters

When the same letter appears twice, its form follows the doubling rule.

A + A = a'a

B + B = bbh

C + C = cch

04 / READING GUIDE

How to read Xythos

Start by identifying the original letters. Then check whether any adjacent letters use a combination rule. Finally, apply spelling rules such as the special form of A at the beginning of a word.

Example: reading a word

Hstenlliou

Hst · En · LLi · Ou

H · E · L · L · O

This example shows how groups of characters can represent individual letters.

Watch the I combinations

ihn'te represents the I + N combination.

ihnte represents the I + T combination.

The apostrophe matters: these two forms must not be confused.

05 / EXAMPLES

Using Xythos

The following example introduces the language through a short message.

hstenlliou, ihn a'm't Xyloto a'sihn ihn't "Xadyehliteou"

ihn'te tehstihnsihn li'an'tegehun'agehen.

hstouwh a'bhoute yehoun?
This Means:
Hello, I Am Xyloto As In "Xadyehliteou"
In This language.

Learning tip

Learn the alphabet first, memorize common combinations next, and then practice reading complete words. Do not assume that every combination follows ordinary English spelling.
